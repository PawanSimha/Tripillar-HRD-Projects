# Project One: Ride Booking History System

This Java program implements a ride booking history system using a linked list.

## Files
- `Main.java` - menu-driven application for adding, displaying, searching, updating, and deleting ride bookings.

## How to compile
```bash
javac "Project 1\Main.java"
```

## How to run
```bash
java -cp "Project 1" Main
```

## Features
- Add new ride bookings
- Display all booking history
- Search booking by ID
- Delete booking by ID
- Update booking details
